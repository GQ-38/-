# 校园二手闲置纯静态网站 - 简化管理版 V2

## 新增图片上传方式

`admin.html` 的商品图片区域现在支持：

- 本地上传：点击“选择本地图片”，可一次选择多张。
- 剪贴板上传：复制图片或截图后，在图片区域按 `Ctrl + V` 直接粘贴。
- 拖拽上传：把多张图片直接拖进图片区域。
- 多次追加：可以先选几张，再粘贴几张。
- 单张删除：每张缩略图右上角有删除按钮。
- 自动压缩：图片会自动压缩成适合网页展示的大小。

## 你现在怎么用

1. 解压文件夹。
2. 双击打开 `admin.html`。
3. 填写商品名称、价格、简介、状态。
4. 在“商品图片”区域添加图片：
   - 点“选择本地图片”；
   - 或截图后直接 `Ctrl + V`；
   - 或把图片拖进去。
5. 点击“保存这个商品”。
6. 点击“保存到本机预览”。
7. 打开 `index.html` 看效果。
8. 没问题后，在 `admin.html` 点击“导出 data/items.js”。
9. 把下载出来的 `items.js` 放进网站的 `data/` 文件夹，覆盖原来的 `items.js`。
10. 重新上传整个网站文件夹，别人就能在线看到。

## 重要说明

这是纯静态网站，没有数据库，所以浏览器不能自动把数据永久写回线上服务器。

管理页解决的是：
- 不用手写商品代码；
- 可以直接网页添加/修改商品；
- 可以本地多图上传；
- 可以剪贴板粘贴图片；
- 可以一键导出新的 `items.js`。

但最终仍然需要你把导出的 `data/items.js` 上传到网站空间。

## 页面说明

- `index.html`：给别人看的商品页面。
- `admin.html`：你自己用的商品管理页面。
- `data/items.js`：商品和联系方式数据。
- `style.css`：页面样式。
- `app.js`：首页展示逻辑。
- `admin.js`：管理页逻辑。
- `images/`：图片目录。如果你在管理页直接选择/粘贴照片，图片会被写入 `items.js`，不一定需要放到这个目录。
