最省事流程：
1. 先点“从 data/items.js 重新读取”，确保编辑列表是最新线上数据。
2. 在左边添加/修改商品。
3. 图片可以点“选择本地图片”，也可以复制图片后在图片框里 Ctrl+V 粘贴。
4. 点击“保存到本机预览”。
5. 打开 index.html?preview=1 确认没问题。
6. 点击“导出 data/items.js”。
7. 用导出的文件替换 GitHub 仓库里的 data/items.js。

注意：纯静态网站不能自动写入线上服务器。管理页能帮你少改代码，但最终仍要上传导出的文件。
